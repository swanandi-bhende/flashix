# GAS OPTIMIZATION

## Summary

Flashix now has a versioned gas budget contract in `contracts/contracts/interfaces/IGasConstants.sol`, a batch-capable executor in `contracts/contracts/ArbitrageExecutorV2.sol`, mirrored Python constants in `agent/gas_optimizer/constants.py`, and gas-profile enforcement in `contracts/gas-report.txt` plus `scripts/check_gas_budget.py`.

The batch rows above reflect the dedicated gas-profile assertions; the `gas-report.txt` artifact is the reporter output used by CI and release checks.

## Storage Layout Analysis

`ArbitrageExecutorV2` keeps the hot-path configuration compact by storing the signer, default token, batch size, and MEV flags together as small scalars instead of spreading them across unrelated slots. The main runtime savings come from avoiding per-trade allowance writes, reducing redundant runtime events, and only charging the execution counter on batch paths.

### Slot Sketch

| Slot | Contents |
| --- | --- |
| 0 | `lendingPool`, `signalValidator`, `profitRecipient`, `trustedSigner` |
| 1 | `defaultBorrowToken`, `maxBatchSize`, `commitmentRequired`, `mevBurnEnabled` |
| 2 | `ethPriceUsdc`, `mevBurnPct`, `mevBurnTotalSpent`, `executionCounter` |
| 3+ | `approvedRouters`, `nonceTimestamps`, `commitmentBlocks` mappings |

## MEV Protection Cost-Benefit

- Private bundle submission keeps the transaction out of the public mempool.
- The on-chain commitment hook lets the contract reject execution without a prior commitment when that mode is enabled.
- The MEV burn path is best-effort and is only activated when the agent chooses to pay for preferential inclusion.

## Gas Price Sensitivity

| Gas price | Single-trade spread needed | Batched spread needed |
| --- | ---:| ---:|
| 10 gwei | Low | Lower |
| 30 gwei | Moderate | Moderate-low |
| 50 gwei | Higher | Moderate |
| 100 gwei | Very high | Still feasible only when batched |

## Reproduce

From the contracts project:

```bash
cd contracts
REPORT_GAS=true npx hardhat test tests/GasOptimization.test.ts
python ../scripts/check_gas_budget.py gas-report.txt
```

## For Judges

The `contracts/gas-report.txt` artifact is generated by Hardhat against compiled contract bytecode, and the `scripts/check_gas_budget.py` check enforces the same budget numbers used by the agent-side estimator.
